# Voice prompts

Download voice prompt embeddings from the official PersonaPlex repository.

## How to get them

1. Clone the PersonaPlex repo: https://github.com/NVIDIA/personaplex
2. Copy the prompt files (e.g. `NATF2.pt`) from the `assets/voices/` directory into this folder.

Example path used by default:

- `assets/voice_prompts/NATF2.pt`
